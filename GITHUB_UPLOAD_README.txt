MARCA-4 GitHub Pages用ファイル

リポジトリ:
https://github.com/liebeseele1002-svg/MARCA-4.git

公開予定URL:
https://liebeseele1002-svg.github.io/MARCA-4/

アップロード方法:
1. このZIPを解凍してください。
2. 解凍した中身をすべてGitHubの MARCA-4 リポジトリへアップロードしてください。
3. ZIPファイルそのものはアップロードしないでください。
4. Commit changes / 変更をコミット を押してください。
5. Settings > Pages で以下を設定してください。
   Source: Deploy from a branch
   Branch: main
   Folder: /root
   Save

アップロードする主な中身:
- index.html
- assets/
- 404.html
- robots.txt
- sitemap.xml
- thanks.html
- .nojekyll
- GITHUB_UPLOAD_README.txt
- BUILD_REPORT.txt

確認済み:
- index.htmlは最上位
- assetsフォルダあり
- 画像パスは相対パス化
- sitemap.xml / robots.txt / canonical / OGP は MARCA-4 URL用
